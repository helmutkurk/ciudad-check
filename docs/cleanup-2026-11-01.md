## Code findings

No application source, tests, flags, dependency pins or lockfiles were changed.
No application-code deletion is claimed: the full check could not be green in this
sandbox. Only homepage back links were repaired; the session context hook and its
existing assertions were updated for ADR-0008.

Candidates with no consumer found in tracked source (review before removal):

| Candidate | Evidence / limit |
|---|---|
| `apps/web/src/lib/router.ts`: `navigate()` | Only its declaration appears; no import/call found. `usePath` and `appForPath` are used and must remain. |
| `apps/web/src/lib/api.ts`: `ApiClient.decision()` | No web caller found. The engine decision endpoint is used by the shell and must remain. Remove the web wrapper/import only after review. |
| `apps/web/src/styles/components.css`: `.dash`, `.dash-list`, `.dash-detail`, their responsive selectors and `.status-line` | No TSX class/data-attribute consumers found; preserve neighboring active selectors such as `.new-check`. |
| `apps/web/src/styles/tokens.css`: `--r-thumb` | Declaration and style-documentation mention found, no `var(--r-thumb)` consumer. |

Live flags are **not dead code**: `FAKE_PAYMENTS`, `VERIFY_CLIENT`, `VERIFIER_MODE`
and `SOKOSUMI_CLIENT` serve tests/local work and real adapters; `PAYMENTS_IMPL=engine-fake`
is referenced by wiring; `CHALLENGE_MODE` implements the ADR-19 fallback;
`ALLOW_TEST_UPLOAD`, `ALLOW_DEMO_OVERRIDE`, `ENABLE_DRY` and `LOCATION_CHECK` have
explicit guards, routes, banners or evidence controls. Their eventual retirement
needs behavior/security review, not a text-only cleanup. Demo stores/jobs are also
referenced by tests and recorded evidence.

Other follow-up candidates: reconcile old component TODOs with verified facts;
review session/worker identity and wallet ownership, polling/reconciliation for
unknown payouts, process-local duplicate memory, and the loopback-only engine bind
before choosing server/container ingress. These are investigations, not confirmed
new defects or permission to change behavior here.
